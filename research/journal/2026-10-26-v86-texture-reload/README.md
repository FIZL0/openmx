# V86 — texture reload

2026-10-26. Task: `./kit plan V86`.

runs is drawn from the next frame, in the GPU and software renderers alike. Each loaded model texture now
remembers its disc key; the ground's pages and layers still reload only with the next ride. Details in the
numbered files; the newest one's suffix says whose move it is (FINAL · PART · READY).
