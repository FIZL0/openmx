Where things sit

  • The original's corners are kept. Score is top left, the radar bottom left (freestyleradar's 87,363) and the speed bottom right, all inside a 4% title-safe margin.
  • The trick popup sits in the upper centre, clear of the bike and the horizon line.
  • Prompts are one low strip at the bottom centre, below the rider. They're a third the height of the original's centred dialog box and never cover the bike or the line ahead.
  • Everything is sized in view-height ems, so split screen and the V52 HUD scale are a single multiplier.

Points popup (P68)

  • Each trick joins the chain with a pop, and the multiplier pill counts the links.
  • A landing turns it green, then the total counts into SCORE. A bail strikes it through in red and nothing is banked.
  • The trick names here are placeholders. The real ones come from the disc's strings once P68 reads them; only Wheelie, Stoppie and BackFlip are named in trick.rs so far.

Minimap

  • It's heading-up like the original, so the rose turns and the player arrow stays fixed. N rides the rim.
  • Blips use the original's set: yellow humans, red AI, the four activity zones (H hit, R run, M machine race, S stunt), idle machines, and numbered markers in slot colours (P94).
  • Anything past the range pins to the rim as a chevron, so a zone or friend is never lost.
  • Off with Minimap Off (V52).

Prompts

  • The machine prompt replaces STR_SWITCH_BIPLANE's dialog ("Would you like to switch to the Biplane?") with one line: the machine's icon, its name and ◯ Switch. It answers the same way through vehicle::Answer (P103).
  • The challenge prompt names the activity and its goal. ◯ is held to start, with a ring filling, so riding through a zone never starts one by accident.
  • Overlay None still shows prompts, because they're how you act. It hides everything else, the marker bar included (P117).

Marker menu (P88, P94, P106, P107)

  • This rebuilds hud::draw_markers as a vector panel. It moves from top centre to the top right corner, opposite SCORE, so the trick popup and a challenge's clock keep the centre.
  • It shows five slot discs in the markers' own colours, solid where set. The selection is ringed and raised.
  • The other players come next as pills with their names (hud::marker_label: "to Kai", or P2 for a seat with no name), then a one-line label and the 200 ms hold bar for ▼ and ▲.
  • It's up 2 s after a change or while a direction is held (MarkerBanner), the same rule as now. The d-pad legend says what each direction does.
  • The header names the machine whose set is up (P107), and the plane's five are its own.
  • A teleport poofs the screen. Markers appear on the radar in the same colours and numbers.
  • Overlay None hides it (P117).

Speed and preload

  • Digital is a big slanted readout in our face, with no bitmap yearlingdash.
  • Analog is a vector dial with the odometer (V42).
  • The preload capsule fills while pumping and turns green when full (V53).
  • The biplane keeps the speed only, as the original does.

Build notes

  • This uses the same M PLUS Rounded 1c subsets and vector pill as the menu concept (P118), so the two ship together.
  • It's drawn on both paths, the GPU one and the software one, as vector quads with no fstyleui.res bitmaps. The disc's icons stay as an "Original art" fallback.
  • The debug overlay (H) stays the port's own and draws on top.
